# API de catálogo para n8n / IA

`GET /wp-json/besthome/v1/propiedades` (`plugins/besthome-easybroker-sync/includes/rest-catalogo.php`, clase `BH_EB_Rest_Catalogo`). Header `X-BH-Key` = `BH_API_KEY` (wp-config.php, mín. 24 caracteres; sin llave responde 503). Sin imágenes ni `bh_priv_*`; `precio` es el `bh_price` real aunque esté oculto en el sitio (el endpoint siempre exige llave) y `precio_visible` (bool) dice si el sitio lo muestra; `condicion` = `nueva | usada | desarrollo | ''`. Filtros: `operacion`, `tipo`, `zona`, `precio_min/max`, `recamaras_min`, `banos_min`, `construccion_min`, `terreno_min`, `amenidad`, `q` (texto), `eb_id` (coincidencia exacta con `bh_eb_id`; con él `visibilidad` por defecto es `todas`), `visibilidad` (`publica` por defecto | `privada` | `archivada` | `todas`), `por_pagina` (50, máx. 200), `pagina`. Cada item incluye `visibilidad` y `origen`.


**Historial de precios** `GET /wp-json/besthome/v1/precios?desde=YYYY-MM-DD` (misma llave `X-BH-Key`; `includes/price-history.php`, clase `BH_EB_Price_History`, máx. 1000 filas). Devuelve `eb_id`, `precio_anterior`, `precio_nuevo`, `moneda`, `fecha` (ISO UTC) y `origen` (`sync` | `manual`). Tabla `{prefix}bh_price_history` (dbDelta, opción `bh_price_history_db_version` = `1`). Cada cambio de `bh_price` dispara `do_action('bh_price_changed', $post_id, $eb_id, $anterior, $nuevo, $moneda, $origen)` para enganchar un webhook (pendiente). Origen `sync` = el cambio ocurre con el transient `bh_eb_sync_lock` activo.
